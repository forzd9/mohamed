# مجموعة بوتات Telegram مستقلة

يحتوي هذا المستودع على **ثلاثة برامج Python منفصلة**، لا على تطبيق واحد متكامل أو حزمة موحّدة. أوصاف الوظائف أدناه مستخلصة من أسماء الملفات والبنية والوظائف الظاهرة في المصدر؛ لم تُشغّل البرامج، ولذلك لا تمثل ضمانًا بأن أي وظيفة تعمل حاليًا.

## البرامج

| الملف | الغرض الظاهر من المصدر | ملاحظات وحدود |
|---|---|---|
| `moha-dow.py` | بوت لتنزيل وسائط من روابط منصات ومصادر مختلفة، ومنها YouTube وInstagram وTikTok وPinterest وFacebook وSnapchat. يتضمن كذلك وظائف بحث/تنزيل صوت أو فيديو، اشتراكًا بالقنوات، وإدارة مستخدمين وحظرًا ووضع صيانة. | يعتمد على عدة مكتبات ومصادر خارجية. يحتوي مسار بدء البرنامج على تثبيت/تحديث تلقائي للحزم؛ وهذا سلوك حساس أمنيًا ويجب مراجعته وإزالته أو جعله يدويًا قبل أي تشغيل. لا يوجد ملف متطلبات يثبت الإصدارات المقصودة. |
| `moha-id.py` | بوت يعرض أدوات مرتبطة بمعلومات حساب Telegram، مثل المعرّف والملف الشخصي والقناة، مع اختيار اللغة وحفظ بيانات المستخدمين محليًا. | وجود الوظائف في الشيفرة لا يثبت دقة تقديرات الحساب أو توافر البيانات التي تعتمد عليها. يستخدم تخزينًا محليًا. |
| `primwoeoeo.py` | بوت لإدارة الإيموجي/الملصقات والمجموعات والبحث والتصنيفات والمفضلة والإحصاءات، مع لوحة إدارة، إرسال جماعي، وإعداد ونشر منشورات فورية أو مجدولة إلى قناة. يتضمن أيضًا وظائف نسخ احتياطي واستعادة واستيراد وتصدير. | يحتوي على عمليات إدارية تغيّر بيانات البوت أو ترسل محتوى للمستخدمين والقنوات. راجع الصلاحيات والوجهات وآليات الاستعادة قبل الاستخدام. |

## البنية والمتطلبات المعروفة

- الملفات الثلاثة مستقلة، ولكل منها نقطة بدء خاصة؛ لا تظهر في المستودع بنية حزم موحدة أو ملف إعداد مشترك.
- المصدر مكتوب لـ **Python**، لكن المستودع لا يحدد إصدارًا أدنى أو نطاق إصدارات مدعومًا.
- لا يوجد `requirements.txt` أو `pyproject.toml` أو ملف إعداد اعتماديات آخر. من المكتبات الخارجية المستوردة في الملفات: `python-telegram-bot` (استيراد `telegram`)، و`pyTelegramBotAPI` (استيراد `telebot`)، و`requests`، و`beautifulsoup4`، و`yt-dlp`، و`instaloader`، و`user-agent`، و`psutil`. هذه قراءة للاستيرادات وليست قائمة اعتماديات موثقة أو مثبتة؛ لم تُحدّد إصداراتها أو تُختبر توافقاتها.
- يستخدم المصدر تخزينًا محليًا يتضمن SQLite وملفات بيانات JSON. لا يشرح المستودع سياسة النسخ الاحتياطي أو الاحتفاظ أو حماية هذه البيانات.

لا يوفّر المستودع تعليمات إعداد أو ملف متطلبات أو إعدادًا موحدًا. لم تُكتشف في المصدر قراءة إعدادات من متغيرات البيئة؛ تظهر أسماء إعدادات مضمّنة في الملفات، ومنها `TOKEN` و`BOT_TOKEN` و`ADMIN_IDS` و`ADMIN_ID` و`CHANNEL_USERNAME` و`CHANNEL_USERNAME2` و`DATA_FILE` و`DB_NAME` و`DOWNLOAD_DIR`. **الأسماء مذكورة للتعريف فقط؛ لا تضع قيم الرموز أو كلمات المرور في README أو في مستودع عام.** انقل أي اعتماد إلى مخزن أسرار مناسب، ودوّر أي اعتماد سبق نشره.


لا تشغّل `moha-dow.py` قبل معالجة التثبيت/التحديث التلقائي للحزم عند البدء ومراجعة مصدر الحزم. لا توجد هنا خطوات تثبيت أو إعداد مؤكدة يمكن تقديمها بأمان دون توثيق الاعتماديات والإعدادات المقصودة. لم تُجرّب هذه الأوامر، ولم يُختبر البناء أو التشغيل أو أي اختبار.
